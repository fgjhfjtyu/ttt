# قابلیت‌های جدید (اندروید)

## پرچم خودکار کشور
هر سروری که دستی وارد و ذخیره کنید، آدرسش به IP تبدیل می‌شود و کشورش با سرویس‌های GeoIP (api.country.is، ipwho.is، ipapi.co) پیدا می‌شود؛ پرچم همان کشور داخل دایره کنار کانفیگ نمایش داده می‌شود. نتیجه داخل خود کانفیگ ذخیره می‌شود. اگر اینترنت/سرویس در دسترس نباشد، موقتاً از روی نام کانفیگ حدس زده می‌شود (مثلاً «آلمان»، «Japan»).

## سرورهای VPN Gate
از منو یا کارت «سرورهای عمومی VPN Gate»: فهرست همهٔ کشورها با پرچم، پینگ و سرعت. جستجو و مرتب‌سازی دارد. لمس سرور = پر شدن فرم؛ دکمهٔ + = ذخیره در کانفیگ‌ها.
اگر vpngate.net در شبکهٔ شما بسته است: اول به یک سرور ذخیره‌شده وصل شوید و فهرست را به‌روز کنید، یا CSV را از سایت کپی و با دکمهٔ کلیپ‌بورد بالای صفحه وارد کنید. آدرس منبع هم قابل تغییر است (فقط https).
